# Чек-лист публикации в RuStore

Сверено с открытыми источниками на 01.11.2026. Перед загрузкой перепроверьте справку RuStore (https://www.rustore.ru/help) — требования меняются.

## Аккаунт и юридическое
- [ ] Аккаунт разработчика в RuStore Консоли (физлицо, ИП или юрлицо), подтверждён.
- [ ] **Верификация разработчика Google и регистрация package name** (`uz.robutpit.znatoki`) — с осени 2026 ограничение действует на уровне ОС Android для сертифицированных устройств: приложение от неверифицированного разработчика может не установиться даже из RuStore. Зарегистрируйте и ключ подписи, которым подписываете сборку для RuStore. Источник: блог RuStore «Google меняет правила установки Android-приложений».
- [ ] Политика конфиденциальности опубликована: `https://game.robutpit.com/legal/privacy` (текст — `store/legal/privacy.html`).
- [ ] Пользовательское соглашение опубликовано: `https://game.robutpit.com/legal/terms`.
- [ ] Контакт поддержки: gtnz1071980@yandex.com.

## Сборка
- [ ] Свой release-ключ создан (см. RELEASE.md) и **сохранён в двух местах**: без него нельзя выпускать обновления.
- [ ] `BuildConfig.USE_MOCK = false` для release (в `app/build.gradle.kts`), когда сервер готов.
- [ ] `SERVER_BASE_URL` в `gradle.properties` указывает на рабочий сервер (только HTTPS).
- [ ] Увеличены `APP_VERSION_CODE` / `APP_VERSION_NAME`.
- [ ] `./gradlew bundleRelease` → `app/build/outputs/bundle/release/app-release.aab` (RuStore принимает AAB, лимит 500 МБ; можно загрузить и APK).
- [ ] При загрузке AAB укажите в консоли ключ подписи (RuStore переподписывает AAB, ключ нужно передать по инструкции консоли), либо загрузите подписанный APK.
- [ ] Сборка проверена на реальных устройствах с Android 8 (API 26) и Android 15/16.

## Карточка
- [ ] Название «Клуб знатоков», краткое и полное описание ru/uz — `store/listing.md`.
- [ ] Иконка 512×512 — `store/icon-512.png`.
- [ ] 3–8 скриншотов с реального устройства (заглушки в `store/screenshots/`).
- [ ] Категория «Викторины», возрастной рейтинг 12+.
- [ ] Список разрешений с обоснованием (из `store/listing.md`).

## Требования к содержимому
- [ ] Нет чужих товарных знаков: не используются название, логотип, музыка и графика телеигры «Что? Где? Когда?». Логотип и звуки свои (см. ASSETS_LICENSES.md).
- [ ] UGC: есть жалобы, блокировки, модерация вопросов и чатов — описано в `store/listing.md`.
- [ ] Удаление аккаунта доступно в приложении (Настройки → Удалить аккаунт) и описано в карточке.
- [ ] Разрешение на микрофон запрашивается с объяснением и только при входе в игру.
- [ ] Нет скрытых платежей и рекламы (если добавите — RuStore Pay SDK / разметка рекламы).

## После публикации
- [ ] Подключить RuStore Push SDK (абстракция `PushProvider` уже есть) и, при желании, RuStore SDK обновлений.
- [ ] Следить за отзывами и крашами в консоли.
