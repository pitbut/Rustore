## 1. Блиц и суперблиц: за три вопроса — ОДНО очко
- Сектор `blitz` / `superblitz` — это **один раунд из трёх вопросов** и стоит **одно очко**.
- Вопросы идут по очереди. **Первый неверный ответ** (или отсутствие ответа) → `+1` зрителям, блиц сразу заканчивается, оставшиеся вопросы не задаются.
- **Все три верных** → `+1` знатокам (только после третьего вопроса).
- После верного ответа на 1-й или 2-й вопрос: `game:reveal` с `scoreDelta: {experts:0, viewers:0}`, `host:say` «Верно! Следующий вопрос.», затем следующий вопрос.
- Сектор помечается сыгранным, когда блиц закончен (ошибка или 3 верных). `game:phase REVEAL` с `sector` = индекс сектора — только в этот момент; для промежуточных вопросов `sector: -1`.
- Апелляция в блице недоступна (`appealable: false`).
- Счёт игры до 6 очков проверяется после каждого начисления.
- Тесты: 3 верных → ровно +1 знатокам; верно-неверно → ровно +1 зрителям и третьего вопроса нет; неверно на первом → +1 зрителям; интеграционный тест «каждый сектор любого типа даёт ровно одно очко».

## 2. Досрочный ответ («Ответ готов», `game:ready_answer`)
- **В блице и суперблице запрещён** → `error {code:"no_early_in_blitz"}`, обсуждение продолжается.
- **Разрешён, только пока до конца обсуждения больше 10 секунд** (`endsAt - now > 10000`). Иначе → `error {code:"early_too_late"}`, обсуждение продолжается до конца.
- Копилка времени: при досрочном ответе остаток (округлённый вниз до 5 с) только **запоминается**. Он **добавляется к `timeBankSec` лишь если ответ оказался верным** (`correct` или `disputed`) — после проверки, перед `game:reveal`. Неверный ответ или отсутствие ответа → копилка не меняется.
- `host:say`: при досрочном — «Досрочный ответ! Если он верный, N секунд уйдут в копилку.»; при верном — «Ответ верный — N секунд уходят в копилку команды.»
- Капитан-бот жмёт досрочный ответ только в обычных вопросах и только пока осталось больше 10 с.
- Тесты: досрочный + верный → копилка выросла; досрочный + неверный → не изменилась; `ready_answer` в блице → `no_early_in_blitz`; при остатке ≤ 10 с → `early_too_late`.
